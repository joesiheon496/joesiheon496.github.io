## 한 줄 요약

기존 점군 업샘플링은 **점을 어디에 놓을지**에 집중했고, **경계(엣지)가 어떻게 생겨야 하는지**는 다루지 않았다. EGP3D는 RGB-D 카메라라는 상황을 활용해 이 빈칸을 채운다.

> 업샘플된 점군을 **카메라 내부·외부 파라미터로 RGB 이미지 평면에 투영**하고, 투영된 점집합의 **concave hull(오목 껍질)** 을 뽑는다. 그리고 그것을 RGB 이미지에서 검출한 **엣지 맵에 맞춘다.** 3D 기하 최적화 문제가 **2D 점집합 두 개를 정렬하는 문제**로 바뀐다.

여기에 Chamfer·Hausdorff·gradient smooth 세 손실을 걸어 기존 업샘플링 모델의 학습에 얹는다. 부수적으로 **노이즈·산광(stray light)이 실제로 들어 있는 RGB-D 점군 데이터셋**을 새로 만들었다.

## 배경 / 문제

논문이 지적하는 것은 셋이다.

1. **엣지가 방치되어 있다.** 대부분의 업샘플링 방법은 정확도와 배율에 집중하고 **엣지 기하**는 신경 쓰지 않는다. [Grad-PU]({{< ref "/posts/grad-pu" >}}), RepKPU, 복셀 기반 방법 등이 기하 최적화를 다루기 시작했지만 **초점은 점의 배치(point placement)이지 명시적인 엣지 기하가 아니다.**
2. **합성 데이터셋의 한계.** PU-GAN, PU1K는 합성 데이터라 **노이즈·산광·데이터 불완전성**이 없다. RGB-D 카메라가 실제로 마주하는 조건과 다르다.
3. **깊이맵을 거치는 우회로의 손실.** RGB 유도라는 발상 자체는 **GDSR**(guided depth map super-resolution)에서 먼저 나왔다. 하지만 깊이맵을 올린 뒤 점군으로 변환하면 필터링·임계처리·보간 과정에서 공간 충실도가 깎인다. **점군에서 직접 하는 게 낫다.**

## 핵심 아이디어

> **RGB 이미지가 3D 경계의 정답지 역할을 할 수 있다.** 2D 엣지 검출은 수십 년간 잘 풀린 문제이고, RGB-D 카메라는 이미 정렬된 RGB를 함께 준다. 그 자산을 3D로 끌어오는 것.

파이프라인은 두 단계다.

```text
[1단계] PU 모델        : 저해상도 점군 P_low → 조밀한 P_U   (밀도 올리기)
[2단계] PCSR 모델      : P_U → 엣지 유도 모듈 → 손실 → PU 모델 갱신
                        (경계 기하 최적화)
```

**PCSR 모델이 PU 모델을 대체하는 게 아니라 감싼다.** 업샘플된 점군을 엣지 유도 모듈에 넣어 손실을 계산하고, 그 손실로 PU 모델을 업데이트한다. 그러면 이후 업샘플링에서 **밀도만 올리는 게 아니라 경계도 함께 최적화**된다.

### PU 모델 — APU-LDI를 그대로 쓴다

기반은 **APU-LDI**의 Local Distance Indicator(LDI)다.

```text
희소 점군 S → 국소 패치 P 로 분할
각 점 주변에 정규분포로 질의점 q 생성
패치 P → 특징 추출기 → 점별 특징 F = {f_h}
질의점 q 주변 kNN 영역 P_q 를 q 중심으로 정렬 → MLP → 상대 특징 F′
어텐션으로 상대 가중치 w_d 예측:

  f_q = Σ_d [ w_d · f′_d + (1 − w_d) · f_d ]            (1)

f_q + 패치 전역 특징 + q 좌표  →  거리 예측기(MLP)  →  점-대-표면 거리 d_l
```

학습된 LDI로 전역 암시적 필드를 구성하고, 질의점을 **예측된 거리와 그래디언트 방향으로 반복 이동**시켜 표면에 붙인다. → 업샘플 점군 `P_U`.

> 이 반복 이동 구조는 [Grad-PU]({{< ref "/posts/grad-pu" >}})와 같은 계열이다. 차이는 Grad-PU가 **점-대-점 거리**를 쓰고 APU-LDI는 **점-대-표면 거리 + 암시적 필드**를 쓴다는 점.

### 엣지 유도 모듈 — 3D를 2D로 접는다

세 단계다.

**① 점군 투영** — RGB-D 카메라가 ToF 방식이므로 내부·외부 파라미터로 업샘플 점군 `P_U = {(x_i, y_i, z_i)}`를 RGB 이미지 평면의 `P_image = {(u_i, v_i)}`로 옮긴다. 엣지 맵 `R_edge`는 **Canny**로 뽑는다(연산 복잡도와 효과를 고려한 선택이라고 부록에 명시).

**② concave hull 계산** — 투영된 점집합의 경계를 구한다. **convex hull이 아니라 concave hull**인 게 중요하다 — 볼록 껍질은 오목한 실루엣(예: 공룡의 다리 사이)을 뭉개버린다. kNN 기반 concave hull 알고리즘으로 `P_hull = {(x_i^hull, y_i^hull)}`를 얻는다.

**③ 통합 좌표계** — `R_edge`와 `P_hull`을 같은 좌표계에 놓으면 원래의 3D 최적화가 이렇게 바뀐다.

```text
min_{P_hull}  f(R_edge, P_hull)                          (2)
```

{{< img src="edge-module.png" alt="RGB 엣지, 투영 점, concave hull 점의 시각화" caption="(좌) RGB 엣지 맵. (우) 투영된 점(파랑)과 그 concave hull(빨강)이 RGB 엣지(초록)와 정렬되어야 한다. 원논문 Figure 8 (Fang, Ye et al., arXiv:2412.11680, 학습용 인용)" >}}

이 그림이 방법의 전부를 설명한다. **초록 윤곽선(RGB 엣지)에 빨간 윤곽선(점군 concave hull)을 맞추는 일.**

## 세 개의 손실

```text
L_CD(R, P) = Σ_{a∈R} min_{b∈P} ‖a−b‖²  +  Σ_{b∈P} min_{a∈R} ‖b−a‖²    (3)
             → 두 윤곽선의 전반적 형상 일치

L_HD(R, P) = max( d(R,P), d(P,R) ),  d(R,P) = max_a min_b ‖a−b‖         (4~6)
             → 최악의 이탈을 줄인다 (CD는 평균, HD는 최댓값)

L_GS(P_hull) = Σ_{i=1}^{N−2} ‖g_{i+1} − g_i‖                            (7)
             → 윤곽선을 따라가며 그래디언트 급변을 억제 = 경계 매끄러움
```

최종 손실:

```text
L = α·L_CD + β·L_HD + γ·L_GS         (8)
α = 1e−5,  β = 1e−2,  γ = 1e−2
```

여기에 **업샘플링 모델 자체의 원래 손실을 더해** 학습한다. `α`가 `β`·`γ`보다 세 자릿수 작은 건 CD가 합산 형태라 값 자체가 크기 때문으로 읽힌다.

**적용 지점**: APU-LDI는 2단계 학습(① LDI 학습 → ② LDI로 전역 암시적 필드 학습)인데, **엣지 유도 모듈을 2단계에 끼운다.** 업샘플 점군 `P_U`를 입력으로 받아 RGB 엣지로 전역 암시적 필드를 갱신한다.

**합성 데이터셋과의 차이가 이 논문의 논거**다. PU-GAN·PU1K는 워터타이트 메시에서 샘플링한 깨끗한 점군이라, RGB-D 카메라의 산광·경계 흐림을 재현하지 못한다.

학습은 패치 페어(희소 256점 → 조밀 1,024점), 테스트는 입력 2,048점 → 정답 8,096점. 점 수가 많은 촬영 점군은 **비닝 전략**으로 다운샘플했다.

## 결과

단위: CD ×10⁻¹, HD ×10⁻², **낮을수록 좋음**.

### EGP3D 데이터셋 (점군 업샘플링 방법 대비)

| 방법 | CD (4×) | HD (4×) | CD (16×) | HD (16×) |
|---|:--:|:--:|:--:|:--:|
| PU-CRN | 0.183 | 0.467 | 0.423 | 0.529 |
| PU-SMG | 0.296 | 0.674 | 0.723 | 0.782 |
| PC²-PU | 0.201 | 0.355 | 0.392 | 0.664 |
| [Grad-PU]({{< ref "/posts/grad-pu" >}}) | 0.224 | 0.329 | 0.142 | 0.463 |
| APU-LDI (베이스라인) | 0.172 | 0.289 | 0.126 | 0.314 |
| **EGP3D (Ours)** | **0.131** | **0.239** | **0.097** | **0.226** |

- 베이스라인 APU-LDI 대비 **CD −24%(4×) / −23%(16×), HD −17% / −28%.** 엣지 손실만 얹어서 얻은 개선이니 폭이 크다.

GDSR 방법들의 출력 깊이맵을 점군으로 변환해 같은 지표로 비교. 테스트 30장.

| 방법 | CD (4×) | HD (4×) | CD (16×) | HD (16×) |
|---|:--:|:--:|:--:|:--:|
| DADA | 5.14 | 2.58 | 4.79 | 2.39 |
| GeoDSR | 4.96 | 2.43 | 4.13 | 2.17 |

논문의 해석: **깊이맵에서 먼저 올린 뒤 점군으로 변환하는 것보다 점군에서 직접 하는 게 일관되게 낫다.** 변환 과정의 필터링·임계처리·보간이 공간 충실도를 깎기 때문.

### 손실 절제

| L_CD | L_HD | L_GS | CD | HD |
|:--:|:--:|:--:|:--:|:--:|
| ✓ | | | 0.147 | 0.249 |
| | ✓ | | 0.141 | 0.253 |
| | | ✓ | 0.185 | 0.262 |
| ✓ | ✓ | ✓ | **0.131** | **0.239** |

- **gradient smooth 단독은 오히려 나쁘다**(CD 0.185). 형상을 맞추는 항이 없으니 당연하다. 그런데 **셋을 합치면 최고**가 된다 — 논문의 표현대로 "그 진짜 가치는 다른 손실과 결합할 때 드러난다".
- ⚠️ 다만 본문 서술과 표가 어긋난다. 본문은 "CD 손실과 HD 손실을 각각 쓰면 CD·HD 지표가 **각각** 개선된다"고 쓰는데, 표를 보면 **`L_CD`만 쓸 때 HD가 더 좋고(0.249 < 0.253), `L_HD`만 쓸 때 CD가 더 좋다(0.141 < 0.147).** 주장과 정확히 반대다. 행 라벨이 바뀐 것일 수도 있다.

### 다른 백본에 얹어보기

| 방법 | CD (4×) | HD (4×) | CD (16×) | HD (16×) |
|---|:--:|:--:|:--:|:--:|
| Grad-PU | 0.224 | 0.329 | 0.142 | 0.463 |
| **Grad-PCSR** | 0.195 | 0.277 | 0.136 | 0.401 |
| APU-LDI | 0.172 | 0.289 | 0.126 | 0.314 |
| **APU-LDI-PCSR** | **0.131** | **0.239** | **0.097** | **0.226** |

**프레임워크로서 이식 가능하다**는 근거다. 다만 개선 폭이 백본에 따라 다르다.

- Grad-PU: CD 0.224 → 0.195 (−13%)
- APU-LDI: CD 0.172 → 0.131 (−24%)

논문의 설명: **Grad-PU는 업샘플 점군에 구멍과 불연속이 생기는 경향**이 있어 경계 개선의 여지가 제한된다. 이미 고품질 점군을 만드는 APU-LDI에서 경계 불연속 해소 효과가 더 크게 나타난다. → **엣지 유도는 좋은 점군을 더 좋게 만들지, 나쁜 점군을 구제하지는 않는다.**

## 한계 (논문이 밝힌 것)

1. **단면(single-sided) 점군.** RGB-D 카메라는 물체의 한쪽 면만 기록하므로 점군이 불완전하다. 전체를 감싸는 표현이 필요한 하류 과제(완전한 3D 복원)에는 제약이 된다.
2. **정밀 캘리브레이션 의존.** 초점거리·베이스라인·노출이 달라지면 RGB와 깊이 채널이 어긋나 왜곡과 품질 저하로 이어진다. 새 데이터셋을 만들 때 특히 중요.
3. **정답 품질에 종속.** 참조 데이터가 불완전하거나 노이즈가 있으면 초해상 결과도 한계에 부딪힌다.

향후 방향으로 다시점 촬영, 자동 캘리브레이션, 정답 품질에 강건한 알고리즘을 제시한다.

## 읽으면서 걸린 것들

1. **손실 절제 표와 본문 서술이 반대다** (위 참조). 표를 그대로 인용하는 게 안전하다.
2. **테스트 분할 비율이 맞지 않는다.** 본문은 "EGP3D 데이터셋에서 약 **15%** 를 무작위로 테스트셋으로 선정"이라고 쓰지만, 실험 설정은 568 학습 / 152 테스트라 **152/720 ≈ 21%** 다.
3. **정답 점 수가 8,096점**으로 적혀 있다. 이 분야 관행(2,048 × 4 = 8,192)과 다르고, 같은 논문의 4× 설정과도 어긋난다. 오타로 보인다.
4. **코드와 데이터셋 공개 언급이 없다.** 데이터셋이 기여의 3분의 1인데 공개 계획이 명시되지 않았다. 이 논문의 가장 아쉬운 부분 — 재현하려면 Okulo P1 카메라로 직접 촬영해야 한다.
5. **게재 학술지가 미정**이다. 양식은 IEEE Transactions인데 제목 줄이 `IEEE TRANSACTIONS ON XX, VOL. XX, NO. X`로 남아 있다. 인용 시 arXiv 프리프린트로 표기하는 것이 정확하다.
6. **엣지 손실이 실루엣 경계만 다룬다.** concave hull은 투영된 점집합의 **바깥 윤곽**이므로, 물체 내부의 엣지(예: 접힌 옷 주름, 구멍 테두리)는 이 손실의 사정권 밖이다. 논문은 이 구분을 명시하지 않는다.

## 메모

- **"잘 풀린 도메인으로 문제를 옮긴다"는 전략의 좋은 예**다. 3D 경계 최적화는 어렵지만 2D 윤곽 정렬은 다룰 수 있다. [GaussianPU]({{< ref "/posts/gaussianpu" >}})가 점군 업샘플링을 2D 이미지 복원으로 우회한 것과 같은 계열의 발상인데, 이쪽은 **감독 신호만 2D에서 가져오고 최적화 대상은 3D 필드로 남겨둔** 점이 더 절약적이다.
- **RGB-D라는 전제가 강점이자 제약이다.** 정렬된 RGB가 공짜로 주어지는 상황에서만 성립한다. LiDAR 단독이나 합성 점군에는 쓸 수 없다. 반대로 RGB-D를 쓰는 실제 시스템(로봇 그리퍼, 실내 스캔)에서는 추가 센서 없이 얻는 이득이다.
- **테이블 IV가 프레임워크의 성격을 정확히 말해준다.** 엣지 유도는 **증폭기**다. 좋은 백본에서 더 큰 이득(−24%), 구멍이 생기는 백본에서 작은 이득(−13%). 새 방법을 얹을 때 이 순서를 고려해야 한다.
- **데이터셋 기여가 실질적이다.** 업샘플링 논문들이 PU-GAN·PU1K에 갇혀 있다는 지적은 이미 [ReLPU]({{< ref "/posts/relpu" >}})(ABC CAD로 확장)나 [GaussianPU]({{< ref "/posts/gaussianpu" >}})(WPC 컬러 점군)에서도 나온다. 실측 RGB-D 페어 데이터는 그중에서도 부족한 축이다 — 공개된다면 값어치가 크다.
- **우리 파이프라인 관점**: RGB-D나 스테레오가 함께 있는 계측 상황이라면, 점군 후처리 단계에서 **RGB 실루엣을 경계 제약으로 쓰는 것**은 추가 하드웨어 없이 시도할 수 있다. 다만 concave hull이 실루엣만 잡으므로 내부 특징이 중요한 대상에는 별도 처리가 필요하다.

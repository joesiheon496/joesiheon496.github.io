## 한 줄 요약

**점의 3D 좌표(∈ℝ³)를 맞히는 건 어렵지만, 스칼라 거리(∈ℝ¹)를 맞히는 건 쉽다.** Grad-PU는 이 관찰 하나로 업샘플링을 다시 짰다. 중점 보간으로 원하는 개수만큼 점을 일단 만들어놓고, **학습된 점-대-점 거리 함수를 경사하강으로 최소화**해 각 점을 정답 표면 쪽으로 밀어 넣는다. 그 결과 **배율이 네트워크에서 완전히 분리**되어 한 번 학습으로 2×, 3×, 7×, 16× 어디든 대응한다.

## 배경 / 문제

기존 업샘플링은 거의 다 세 단계였다. **특징 추출 → 특징 확장 → 좌표 예측.** 여기에 두 가지 고질병이 있다.

1. **배율 고정.** 특징 확장 유닛이 배율 R마다 맞춤 설계라, 4×와 16×를 쓰려면 모델을 두 번 학습해야 한다.
2. **아웃라이어와 수축(shrinkage) 아티팩트.** 3D 좌표나 잔차를 정확히 맞히는 게 어려워서, 점이 표면 밖으로 튀거나 형상이 안쪽으로 쪼그라든다. 배율이 높아질수록 심해진다.

이웃 점의 아핀 결합이나 암시적 함수로 첫 번째 문제를 푼 방법들(NePs 등)은 있었지만, **두 번째 — 좌표 예측의 부정확성 — 은 그대로 남아 있었다.**

## 핵심 아이디어

> 문제를 **점 생성**과 **위치 정제**로 분리하고, 정제를 **최적화 문제**로 바꾼다.

```text
P_L  --(중점 보간)-->  P_I  --(반복 경사하강)-->  P_H
                       ↑ 여기서 배율이 결정됨 (네트워크와 무관)
```

### ① 중점 보간 — 유클리드 공간에서 점을 만든다

특징 공간에서 확장하지 않고, **좌표 공간에서 직접** 만든다.

1. **중점 생성**: 각 점 `p`와 그 k-최근접 이웃 `p_k`의 중점 `(p + p_k)/2`를 새 점으로 삼는다.
2. **FPS(최원점 샘플링)**: 중복 생성된 중점을 걸러내고, 원하는 배율 `R`에 맞게 개수를 줄인다.

네트워크 학습과 점 생성이 완전히 분리되므로 **배율은 추론 시점에 정하면 된다.**

### ② 점-대-점 거리 — 표면을 추출하지 않는다

정제하려면 "얼마나 틀렸는지"를 재는 자가 필요하다. SDF·UDF 같은 **점-대-표면** 거리를 쓸 수도 있지만, 희소한 저해상도 점군에서 표면을 제대로 뽑아내는 게 항상 가능한 건 아니다.

그래서 **부호 없는 점-대-점 거리**를 쓴다. 보간된 점 `p`에 대해 `F(p)` = 정답 조밀 점군 `P_G`에서 가장 가까운 점까지의 유클리드 거리. 표면이 필요 없고 **임의의 위상(topology)** 을 다룰 수 있다.

### ③ 경사하강으로 정제

```text
p_{t+1} = p_t − λ ∇F(p_t),    t = 0, ..., T−1
```

거리 `F`가 줄어드는 가장 가파른 방향으로 점을 조금씩 옮긴다. 논문은 `T = 10`회 반복을 쓴다.

문제는 추론 시 `P_G`가 없어 `F`를 계산할 수 없다는 것. 그래서 **미분 가능한 근사자 P2PNet**을 학습시킨다.

## P2PNet

{{< img src="p2pnet.png" alt="P2PNet 구조: 특징 추출기와 거리 회귀기" caption="P2PNet — 특징 추출기(P3DConv 기반 dense block ×3)와 거리 회귀기. 학습 경로는 Jitter를 거치고, 추론 경로는 반복마다 특징 보간만 다시 한다. 원논문 Figure 3 (He et al., arXiv:2304.11846, 학습용 인용)" >}}

**특징 추출기** — P4Transformer의 Point 4D Convolution을 공간 축에만 적용해 **P3DConv**로 단순화했다.

```text
f' = Σ_{p_k ∈ K(p)}  γ( α(δx, δy, δz) ⊙ β(f_k) )
```

이웃과의 좌표 오프셋 `(δx, δy, δz)`로 **컨볼루션 커널을 생성**해 이웃 특징에 곱한다. MLP → dense block ×3 구조로 다중 스케일 지역 특징 `{l⁰, l¹, l², l³}`을 뽑고, max pooling으로 전역 특징 `g`를 얻는다.

**거리 회귀기** — 질의점 `p`에 대해 세 최근접 이웃의 **역거리 가중 보간**으로 지역 특징을 만들고, 전역 특징과 함께 4층 MLP에 넣어 거리를 회귀한다.

```text
F(p) ≈ P2PNet(p) = ψ(p, l⁰_p, l¹_p, l²_p, l³_p, g)
```

**추론 시 트릭**: 추출된 특징은 고정해두고, 반복마다 **점이 움직였으니 특징 보간만 다시** 한다. 네트워크 forward를 매번 다시 돌리지 않는다.

### 학습에는 반복이 없다

추론은 반복 최적화지만 **학습은 한 번**이다. 대신 보간된 점에 **가우시안 노이즈 `N(0, 0.02²)`를 주입(jitter)** 해 질의점을 만든다. 이게 "여러 반복 단계에서 점이 얼마나 떨어져 있을지"를 시뮬레이션하는 역할을 하고, 학습된 거리 함수를 **매끄럽고 연속적**으로 만든다. 손실은 예측 거리와 실제 거리의 **L1**.

> 이 jitter 하나로 CD가 0.520 → 0.404 로 개선된다 (PU1K 4×). 반복 최적화를 학습에서 흉내 내는 값싼 방법.

### 강건성과 하류 과제

- **노이즈** τ=0.02에서 CD 0.766 / HD 7.339 로 전 방법 중 1위. 노이즈가 셀수록 격차가 커진다.
- **분류** (ModelNet40, CurveNet): 저해상도 256점 68.76% → Grad-PU 업샘플 후 **91.96%** (고해상도 원본 93.72%). 비교 대상 중 최고.
- **표면 복원** (BallPivoting): CD 0.071로 최고. 다만 저해상도 입력도 0.106이라 개선 폭 자체는 크지 않다 — 논문도 "marginal"이라고 인정한다.

## 절제 실험이 말해주는 것

이 논문의 절제 실험은 유난히 설득력 있다. **주장이 숫자로 정확히 검증된다.**

**거리 회귀 vs 좌표 예측** (PU1K 4×) — 같은 네트워크의 출력 채널만 바꿔 비교:

| 예측 대상 | CD | HD | P2F |
|---|:--:|:--:|:--:|
| 3D 좌표 오프셋 (end-to-end) | 1.170 | 11.834 | 2.521 |
| 3D 좌표 오프셋 (자기회귀 반복) | 0.663 | 7.034 | 1.935 |
| **점-대-점 거리** | **0.404** | **3.732** | **1.474** |

**CD가 1.170 → 0.404.** 반복 갱신만으로도 좋아지지만(0.663), 거리를 예측하는 쪽이 압도적이다. 논문의 출발 가설 — "ℝ³보다 ℝ¹이 쉽다" — 이 그대로 확인된다.

**갱신 전략** — Chibane 등의 UDF 투영 방식(예측 거리만큼 정규화된 음의 그래디언트 방향으로 이동)과 비교:

| 전략 | CD | HD | P2F |
|---|:--:|:--:|:--:|
| `p − P2PNet(p)·∇P2PNet(p)/‖∇P2PNet(p)‖` | 0.872 | 8.650 | 2.541 |
| **`p − λ∇P2PNet(p)`** | **0.404** | **3.732** | **1.474** |

이유가 명쾌하다. **UDF 투영은 거리 크기와 방향이 둘 다 정확해야 하지만, 경사하강은 방향만 맞으면 된다.** 방향만 맞으면 충분한 반복과 적절한 스텝으로 수렴이 보장된다.

**P3DConv vs EdgeConv** — 비슷한 파라미터 수(67.1 vs 71.2 KB)에서 CD 0.404 vs 0.878. EdgeConv는 파라미터 대부분을 개별 특징 정제에 쓰는 반면 P3DConv는 **특징 집약**에 쓴다는 게 논문의 설명.

**보간 결과 `P_I`의 이중 역할** — `P_I`를 네트워크 입력으로도, 갱신 대상 초기값으로도 쓰는 게 최선(CD 0.404). 가우시안 분포에서 뽑은 초기값 `P_S`를 쓰면 0.654로 나빠진다. 중점 보간이 **좋은 출발점**이라는 뜻.

## 메모

- **"어려운 걸 예측하지 말고 쉬운 걸 예측한 뒤 반복하라"** 는 패턴은 업샘플링 바깥에서도 통한다. 확산 모델이 노이즈를 예측하고 반복하는 것, [PUFM++]({{< ref "/posts/pufm-plus-plus" >}})가 속도장을 예측하고 적분하는 것과 같은 계열의 발상이다. 한 번에 정답을 맞히는 대신 **정답으로 가는 방향**만 맞히면 된다.
- **거리 함수를 학습한다는 점에서 UDF 계열과 닮았지만 결정적으로 다르다.** UDF는 표면까지의 거리이고 표면 추출을 전제한다. 여기서는 **정답 점군의 최근접 점까지의 거리**라 표면 개념이 아예 없다. 그래서 열린 곡면·얇은 구조·임의 위상에 자유롭다.
- **속도 우위가 어디서 오는지 주의해서 읽어야 한다.** 논문도 밝히듯 kNN 탐색 같은 비싼 연산은 네트워크 바깥이라 모델 크기와 추론 시간이 비례하지 않는다. 67 KB라는 숫자는 인상적이지만 반복 T회의 특징 보간 비용이 따로 든다.
- **[PUtPFS]({{< ref "/posts/putpfs" >}})와 대비하면 재밌다.** 둘 다 "표면 근처로 점을 끌어당긴다"는 목표는 같은데, Grad-PU는 그 방향을 **학습**하고 PUtPFS는 **DCT 기저 중첩으로 계산**한다. Grad-PU가 정확도에서 앞서지만 학습 데이터가 필요하고, PUtPFS는 그 반대다.
- 이 논문은 [GaussianPU]({{< ref "/posts/gaussianpu" >}})에서 기하 업샘플링 SOTA 비교군으로 쓰인다. 다만 거기서는 **패치 단위 처리 때문에 블록 경계가 드러난다**는 약점이 지적된다 — 이 논문 자체에서는 다루지 않는 문제다.

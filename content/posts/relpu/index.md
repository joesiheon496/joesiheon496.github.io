## 한 줄 요약

**업샘플링 네트워크는 거의 예외 없이 패치 단위로 학습한다.** 패치는 국소 디테일을 잘 보지만, 물체 전체의 형상 정보는 애초에 입력에 없다. ReLPU는 같은 점군을 **균등 분할(Average Segment, AS)** 한 것을 전역 입력으로 하나 더 넣고, **완전히 동일한 오토인코더 두 개**로 병렬 추출해 특징을 이어 붙인 뒤 공유 디코더로 보낸다.

**프레임워크**라는 점이 핵심이다. 인코더-디코더 구조라면 어떤 백본에도 끼울 수 있고, 논문은 MPU·PU-GCN·Dis-PU·PUCRN 넷에 얹어 검증했다.

## 배경 / 문제

패치 기반 파이프라인의 구조적 약점은 이렇다.

> 점군의 각 점은 독립적이라, **정보가 희박한 영역**(희소하거나 가려진 곳)에서는 국소 특징만으로 형상을 이해할 수 없다. 이건 점군 완성(completion) 과제가 마주하는 문제와 같은 성질이다.

기존 대응은 두 갈래였다.

1. **정제기(refiner)로 coarse 점군에서 지역·전역 특징을 합친다** (Dis-PU, PUCRN 등). 하지만 인코더가 하나뿐이라 **교차 스케일 특징의 정합**이 보장되지 않는다.
2. **BiPU처럼 비대칭 전용 인코더를 각각 둔다.** 그런데 "전역·지역 전용 특징 추출기가 정말 따로 필요한가?"는 여전히 열린 질문이었다.

ReLPU의 대답은 **"같은 인코더를 두 개 쓰면 된다"** 다. 특수 모듈을 만들지 않고 **입력 쪽에서** 지역/전역을 나눈다.

## 핵심 아이디어

### 두 가지 입력

```text
전체 모델 M점
 ├─ Patch  입력 : K개 패치로 분할 → 국소 디테일          (기존 방식)
 └─ AS     입력 : M점을 균등하게 K개 부분집합으로 분할     (추가)
                 P_k = { p_i | (k−1)·M/K + 1 ≤ i ≤ k·M/K }
```

AS는 이름 그대로 **균등 분할**이다. 패치처럼 공간적으로 뭉친 덩어리가 아니라, 전체에 걸쳐 고르게 흩어진 부분집합이라 **물체의 전체 윤곽이 각 조각에 들어 있다.** 이게 전역 사전지식 역할을 한다.

### 병렬 vs 순차

논문은 두 변형을 비교한다.

| 변형 | 구조 |
|---|---|
| **ReLPU-** | 두 입력을 **데이터 차원에서 합쳐** 하나의 오토인코더에 순차 투입 (`2B × N × 3`) |
| **ReLPU** | 두 입력을 **동일 구조의 오토인코더 두 개**에 병렬 투입 → `F_concat = [F_global, F_local] ∈ ℝ^{m×2d}` → 공유 디코더 |

손실은 **Chamfer 거리 하나**로 끝. 추가 손실항이 없다.

## Saliency map — 왜 좋아지는지 보기

이 논문이 다른 업샘플링 논문과 구별되는 지점. 점군 **분류·검출**에는 saliency map이 흔히 쓰였지만 **업샘플링**에서는 거의 없었다.

각 점의 기여도를 구면 좌표에서 정의한다.

```text
s_i = − (∂L / ∂r_i) · r_i^{1+α}
      r_i = 점군 중심(centroid)에서 점 i까지의 반경
```

CD 손실을 backward해서 입력점 그래디언트를 얻고, 여기에 **중심으로부터의 반경을 곱해** 강조한다. 발상은 "같은 그래디언트라도 중심에서 먼 점이 구조적으로 더 중요하다"는 것.

{{< img src="fig-saliency.jpg" alt="ReLPU와 원본 모델의 saliency map 비교" caption="네 백본에 대해 patch(지역) 입력과 AS(전역) 입력의 saliency를 비교. ReLPU에서 원거리 엣지 점의 기여도가 높아진다는 게 논문의 주장. 원논문 Figure 3 (Zhang & Wang, arXiv:2501.07076, 학습용 인용)" >}}

논문의 관찰: **기존 패치 기반 방식은 중심에서 먼 엣지 점의 기여도가 낮게 나온다** — 즉 그 점들을 제대로 쓰지 못하고 있다. ReLPU에서는 반경과 무관하게 각 점이 반복적으로 고려된다. `r`과 `s_i`의 단순 선형회귀 기울기가 0에 가까워지는 것으로 이를 정량화했다.

읽는 법:

- **약한 백본일수록 이득이 크다.** MPU는 CD 4.973 → 4.528(−9%), P2F 29.357 → 25.894(−12%). 반대로 이미 강한 PUCRN에서는 개선 폭이 미미하다.
- **512점 입력에서 ReLPU(PUCRN)의 CD는 오히려 나빠진다** (3.605 → 3.625). 논문도 이를 인정하며 "PUCRN의 3단계 순차 정제가 이미 지역·전역 불일치를 줄이고 있어서"라고 설명한다.
- **P2F 개선이 가장 일관적**이다. 2048점 입력에서 네 백본 모두 개선(15.823→13.086, 10.291→8.317, 8.189→7.744, 6.633→5.682). 표면 밀착도는 확실히 좋아진다.

## 읽으면서 걸린 것들

1. **Saliency 수식과 Algorithm 1이 어긋난다.** 본문 수식은 `s_i = −(∂L/∂r_i)·r_i^{1+α}`로 **그래디언트의 부호를 유지**하는데, Algorithm 1은 `saliency = |data.grad|`로 절댓값을 취한 뒤 `−saliency·r`을 쓴다. 절댓값을 씌우면 결과가 항상 ≤ 0이 되어 원 수식과 다른 양이 된다. Figure 3 캡션의 "높은 값이 높은 saliency"와도 부호 관계를 따져봐야 한다. **재현하려면 이 부분을 직접 정해야 한다.**
2. **기여도 정의 서술이 혼란스럽다.** 3.2절은 "ΔL_x가 작으면 기여도가 높다"고 썼다가, 곧 "s_i가 크면(양수) 기여도가 크다"고 쓴다. 두 문장이 같은 것을 말하는지 불분명하다.
3. **"세 가지 지표"라며 네 개를 나열한다** (CD, HD, P2F, Uniform Metric). 사소하지만 교정이 안 된 흔적.
4. **코드가 공개되지 않았다.** 프레임워크를 파는 논문인데 이게 가장 아쉽다. "백본만 갈아 끼우면 된다"는 주장을 검증하려면 결국 직접 구현해야 한다.
5. **표에서 화살표(↓) 표기가 최저값에만 붙어 있어**, 열별 최고 성능이 어디인지 표만 보고는 즉시 안 잡힌다.

## 메모

- **아이디어 자체는 단순하고 이식성이 높다.** "AS로 전역 입력을 하나 더 만들고 인코더를 복제한다" — 구현 난이도가 낮고, 손실도 CD 그대로다. 손댈 게 적다는 건 실무에서 큰 장점이다.
- **다만 얻는 것과 잃는 것이 뚜렷하다.** P2F·균일도는 대체로 개선, CD는 백본에 따라 오차 범위, 파라미터는 1.5~1.7배. **표면 품질이 중요하고 메모리 여유가 있을 때** 쓸 카드다.
- **"약한 백본에서 이득이 크다"는 패턴을 뒤집어 보면**, 강한 백본은 이미 다단계 정제로 전역 정보를 어느 정도 확보하고 있다는 뜻이다. 그렇다면 이 프레임워크의 가치는 **성능 상한을 올리는 것보다 단순한 백본으로 비슷한 품질을 내는 것**에 있을 수 있다.
- **saliency map을 업샘플링에 가져온 시도는 그 자체로 볼 만하다.** 업샘플링 논문은 대개 CD/HD/P2F 숫자와 확대 그림으로 끝나는데, "어느 점이 결과에 기여했는가"를 묻는 도구가 하나 늘어난 셈. 다만 위의 수식 불일치 때문에 그대로 쓰기 전에 검증이 필요하다.
- **[PU-Mask]({{< ref "/posts/pu-mask" >}})와 문제의식이 겹친다.** 둘 다 "패치만 보면 부족하다"에서 출발하는데, ReLPU는 **입력을 하나 더 넣어** 풀고 PU-Mask는 **가상 마스크로 채울 곳을 지정해** 푼다. ReLPU 논문 자체가 PU-Mask를 관련연구로 인용한다.

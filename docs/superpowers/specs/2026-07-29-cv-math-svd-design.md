# 컴퓨터 비전 수학 시리즈 — 2편 "SVD"

작성 2026-07-29. 대상 저장소 `joesiheon496.github.io` (Hugo + PaperMod).
1편 스펙: `2026-07-29-cv-math-transform2d-design.md`

## 목표

수학을 잘 모르는 독자가 **왜 모든 행렬이 회전-스케일-회전으로 쪼개지는지**, 그리고
**특이값이 무엇을 알려주는지** 를 직접 만져보며 이해한다.

## 글의 축

한 문장으로 묶는다.

> **특이값은 "그 방향이 얼마나 잘 정해졌는지"를 알려준다.**

기하(타원의 두 반지름) → 조건수 → 의사역행렬(작은 σ 가 폭발을 만든다) →
최소자승(데이터가 방향을 얼마나 정하는가) 이 전부 이 문장의 변주다.
축이 하나여야 범위가 넓어도 글이 흩어지지 않는다.

## 1편과의 연결

1편에서 데모의 homography 네 점을 일직선에 가깝게 모으면
`특이 행렬 — 네 점이 퇴화했다` 예외가 나서 `try/catch` 로 막았다.
**2편이 그 예외를 설명한다.** σ₂ → 0 이면 행렬이 평면을 직선으로 뭉개고,
역행렬이 존재하지 않는다.

두 번째 연결: 1편 데모의 "각도 보존" 판정은 실은 **σ₁ = σ₂** 와 같은 조건이다.
1편에서 "사잇각 90° 고정"으로 보여준 것을 2편이 특이값으로 설명한다.
이 대응은 **테스트로 검증한다**(§5).

## 범위

**포함**
1. 기하: 회전-스케일-회전 분해, 원 → 타원, 특이값·특이벡터
2. 조건수 σ₁/σ₂, 퇴화(σ₂ = 0)
3. 의사역행렬 — 데모 1 의 readout 으로 (별도 데모를 만들지 않는다)
4. 최소자승: SVD 로 점들에 직선 맞추기 (데모 2)

**제외** (별도 스펙)
- 저랭크 이미지 압축, PCA 정식 설명
- Lie algebra, 카메라 캘리브레이션
- Gradient Descent, Levenberg–Marquardt

의사역행렬을 별도 데모로 만들지 않는 이유: 데모 1 이 이미 SVD 를 계산하므로
readout 추가는 거의 공짜인데, 별도 데모로 만들면 데모 1 의 변주에 가까워
독자가 새로 배우는 것이 적다. 데모 2 는 "데이터 → 구조" 라는 다른 그림을 준다.

## 2. svd2x2 알고리즘

닫힌 형식(E·F·G·H 와 두 각으로 U, V 를 얻는 방식)을 **쓰지 않는다.**
스펙 작성 중 실제로 구현해 보니 특이값은 맞는데 각도 규약을 잘못 조합하기 쉬워
재구성이 깨졌다. 규약을 추측해야 하는 코드는 쓰지 않는다.

대신 자명하게 옳은 경로를 쓴다.

1. \(B = A^\top A\) — 대칭 준양정 2×2
2. \(B\) 의 고윳값 \(\lambda_1 \ge \lambda_2 \ge 0\), \(\sigma_i = \sqrt{\lambda_i}\)
3. \(\lambda_1\) 의 고유벡터가 \(v_1\), 직교 보완이 \(v_2\)
4. \(u_i = A v_i / \sigma_i\) (단 \(\sigma_i > 10^{-12}\))

퇴화 처리를 명시한다.
- \(\sigma_2 \le 10^{-12}\) → \(u_2\) 를 \(u_1\) 의 직교 보완으로 채운다
- \(A = 0\) → \(u_1 = (1, 0)\)
- \(B\) 가 이미 대각(\(q \approx 0\)) → 큰 대각 원소 쪽을 \(v_1\) 으로

반환값: `{s1, s2, v1, v2, u1, u2}` (벡터는 `[x, y]`). σ 는 항상 0 이상이다 (표준 규약).

### 반사가 든 행렬 — 단계 애니메이션에 필요한 추가 형태

\(V\) 는 \(v_2 = (-v_{1y}, v_{1x})\) 로 만들므로 **항상 회전**(det = +1)이다.
그러나 \(U\) 의 det 은 \(\mathrm{sign}(\det A)\) 를 따라가므로, `det(A) < 0` 이면
\(U\) 가 **반사**가 된다. 회전만으로는 \(t = 3\) 에서 \(A\) 에 도달할 수 없다.

그래서 `svdRotationForm(A)` 를 함께 제공한다: `det(U) < 0` 이면 \(u_2\) 를 뒤집고
\(\sigma_2\) 에 음수 부호를 준다. 그러면 \(U\), \(V\) 가 모두 회전이 되고
\(\Sigma = \mathrm{diag}(\sigma_1, \pm\sigma_2)\) 가 된다.

**실측 확인**: 이 형태로도 재구성 오차는 0 또는 머신 정밀도였다
(`[[-1,0],[0,1]]`, `[[0,1],[1,0]]`, `[[2,0],[0,-3]]`, `[[1,2],[3,1]]` 전부 `det(U) = +1`).

이것은 우회가 아니라 **교육적으로 더 좋다.** 반사가 든 행렬은 데모에서 도형이
선분으로 뭉개졌다가 **뒤집혀 나오는** 것으로 보인다. 부호가 붙은 σ₂ 가 그 뒤집힘이다.
readout 에는 특이값으로 \(|\sigma_2|\) 를 쓰고, 부호는 "뒤집힘" 표시로 따로 알린다.

`pseudoInverse2x2(A, tol)` 는 \(V \Sigma^{+} U^\top\) 로 만들고,
\(\sigma_i \le\) `tol` 인 성분은 0 으로 버린다.

**검증 결과** (스펙 작성 중 41개 케이스로 실측):
재구성 오차 최대 4.4e-16, 정규직교 오차 최대 2.7e-11.
정규직교 오차가 머신 정밀도보다 큰 이유는 σ₂ 가 작지만 0 은 아닌 악조건에서
나눗셈이 오차를 증폭시키기 때문이다. **테스트 허용오차는 1e-9 로 잡는다** —
1e-12 로 잡으면 간헐적으로 실패한다.

## 3. 데모 1 — 행렬이 원을 타원으로

**컨트롤**
- 슬라이더 4개: `a`, `b`, `c`, `d` — 행렬 원소를 직접 준다.
  1편의 분해 파라미터(θ, sx, sy, shear)를 쓰지 않는 이유: 그러면 SVD 가
  "또 다른 분해" 가 되어 두 분해가 경쟁하며 헷갈린다. **임의의 숫자 네 개를
  넣었는데 항상 회전-스케일-회전으로 쪼개진다**는 것이 이 글의 요점이다.
- 슬라이더 `t` ∈ [0, 3] — 단계. 이것이 "모든 행렬은 회전-스케일-회전"을
  눈으로 만드는 장치다.
  - `t` 0→1: 원에 \(V^\top\) 적용 (회전)
  - `t` 1→2: \(\Sigma\) 적용 (축 방향 스케일)
  - `t` 2→3: \(U\) 적용 (회전)
  - `t` = 3 의 결과는 \(A\) 를 한 번 곱한 것과 같다

  각 구간은 **행렬 원소를 보간하지 않는다.** 원소를 보간하면 중간에 뒤집힘이 생겨
  회전으로 보이지 않는다. 대신 구간별로 매개변수를 보간한다.
  회전각과 스케일은 `svdRotationForm(A)` 의 값을 쓴다 (σ₂ 에 부호가 붙은 형태).
  - `t` ∈ [0,1]: \(R(\alpha \cdot \theta_V)\), \(\alpha = t\), \(\theta_V\) 는 \(V^\top\) 의 회전각
  - `t` ∈ [1,2]: 위 결과에 \(\mathrm{diag}(1 + \beta(\sigma_1 - 1),\ 1 + \beta(\sigma_2 - 1))\),
    \(\beta = t - 1\) — 스케일을 1 에서 σ 로 보간한다.
    σ₂ 가 음수면 이 구간에서 도형이 **선분을 지나 뒤집힌다** — 반사가 눈에 보이는 지점
  - `t` ∈ [2,3]: 위 결과에 \(R(\gamma \cdot \theta_U)\), \(\gamma = t - 2\)

  `t` = 3 에서 결과가 \(A\) 를 한 번 곱한 것과 **정확히** 일치해야 한다. 이것이
  이 데모의 검증 조건이고 §6-4 에서 확인한다.

**그리기**
- 단위원(64각형): 흐린 색으로 항상 표시
- 현재 단계의 도형: 진한 색
- 화살표: 입력 쪽 \(v_1, v_2\) (단위 길이), 출력 쪽 \(\sigma_1 u_1, \sigma_2 u_2\)
  — 타원의 두 반축이 정확히 이 두 화살표다

**readout**
- σ₁, σ₂
- 조건수 σ₁/σ₂ (σ₂ = 0 이면 `∞`)
- **각도 보존 = σ₁ = σ₂** — 1편 readout 과의 대응을 명시
- \(A^{-1}\) 과 절단 \(A^{+}\) 를 나란히. σ₂ 를 0 에 가깝게 만들면
  \(A^{-1}\) 의 숫자가 폭발하고 \(A^{+}\) 는 유한하게 남는다
- σ₂ = 0 이면 타원이 선분으로 붕괴하고 "역행렬 없음" 을 표시

## 4. 데모 2 — 점에서 직선을 뽑는다

- 드래그 가능한 점 6개. 초기 배치는 대략 직선 위에 흩어놓는다
- 점들을 중심화한 뒤 2×N 데이터 행렬의 SVD
  - \(u_1\) 방향이 직선 방향, \(u_2\) 가 법선
  - 맞춘 직선을 그린다 (총최소자승 = 직교 회귀)
- 화살표로 \(\sigma_1 u_1\), \(\sigma_2 u_2\) 표시
- readout: σ₁, σ₂, **σ₂/σ₁**
  - 0 에 가까우면 점들이 직선에 가깝고 방향이 잘 정해진다
  - 1 에 가까우면 점들이 뭉쳐 있어 방향이 정해지지 않는다
- 점을 한 곳에 모으면 σ₂/σ₁ → 1 이 되고 직선이 의미를 잃는 것을 체감한다

데이터가 2×N 이므로 2×2 공분산 \(C = D D^\top\) 를 만들고 `svd2x2(C)` 를 재사용한다.
\(C\) 는 대칭 준양정이므로 그 SVD 가 고윳값 분해와 같고, 방향벡터 \(u_1, u_2\) 는
데이터 \(D\) 의 특이벡터와 동일하다.

> ⚠️ **주의**: `svd2x2(C)` 가 돌려주는 특이값은 \(C\) 의 것이고, 이는 데이터 \(D\) 의
> 특이값의 **제곱**이다. readout 에 쓸 값은 \(\sigma_i(D) = \sqrt{s_i(C)}\) 다.
> 이걸 빼먹으면 σ 가 제곱된 값으로 표시된다.
> 다만 **비율 σ₂/σ₁ 은 제곱근을 취하기 전과 후가 다르다**(\(\sqrt{s_2/s_1}\) vs \(s_2/s_1\)) —
> 비율도 제곱근을 취한 값으로 표시한다.

## 5. 테스트

`svd2x2` 는 규약 실수를 잡을 수 있는 형태로 검증한다. 전부 브라우저 없이 돈다.

1. \(U \Sigma V^\top\) 가 \(A\) 를 재구성한다 — 결정적 목록 40개 이상, 허용오차 1e-9
2. \(U^\top U = I\), \(V^\top V = I\) — 허용오차 1e-9
3. \(\sigma_1 \ge \sigma_2 \ge 0\)
4. 회전행렬 → σ₁ = σ₂ = 1
5. `diag(3, 0.5)` → σ = 3, 0.5
6. `[[1,1],[1,1]]` → σ₂ = 0
7. 영행렬 → σ₁ = σ₂ = 0, 그리고 예외 없이 반환
8. `pseudoInverse2x2`: 가역 행렬에서는 \(A^{+} = A^{-1}\)
9. `pseudoInverse2x2`: 특이 행렬에서 유한한 값을 반환한다
10. **1편 연결**: `preservation(M).keepsAngle` 이 참이면 σ₁ = σ₂ 다
11. `svdRotationForm`: \(U\), \(V\) 의 det 이 **항상 +1** 이다 (반사가 든 행렬 포함)
12. `svdRotationForm`: 부호 있는 σ₂ 로도 \(A\) 를 재구성한다
13. `svdRotationForm`: `det(A) < 0` 이면 σ₂ 가 음수, `det(A) > 0` 이면 양수다

10번이 두 편을 코드로 잇는 테스트다. 11~13번은 단계 애니메이션이 `t` = 3 에서
\(A\) 와 정확히 일치하기 위한 전제를 지킨다.
